# NEON VEIL story and production bibles

Read these before planning or building any level, mission, character, district or piece of signage.

| File | Covers |
|---|---|
| `Continuity.md` | **Start here.** Canon districts, every invented name and what it maps to, transit map, story spine, build position, open decisions. Keep it updated. |
| `Master_Blueprint.txt` (PDF: `NEON_VEIL_Complete_Game_Design_Blueprint.pdf`, local only) | The 20-section master design blueprint: world, characters, AION, five acts, systems. Story canon, highest authority. |
| `Act_I_Build_Bible.txt` (PDF: `Neon_Veil_Act_I_UE5_Build_Bible.pdf`, local only) | Act I "The Fall": M00 The Glass Crown, M01 Black Protocol, M02 Below the Veil; art direction, tech architecture, performance targets. Cited in the QA docs as "Bible §n". |
| `Campaign_Continuation_Bible.txt` (PDF: `Neon_Veil_Campaign_Continuation_Bible_Act2_and_beyond.pdf`, local only) | Acts II–V, missions M03–M24, characters, districts, bosses, milestone gates. |

Order of authority (continuation bible §19): (1) the master blueprint (`Master_Blueprint.txt`), (2) the Act I bible, (3) the
continuation bible. The Unreal project is authoritative for implemented class and asset names. Report conflicts
before changing code.

Canon quick reference: city **Veyra-9**; nine districts: Crown Sector, the Gutter, Chrome Mile, Floodworks,
Helix Ward, the Spindle, Ashfall, Nullworks, Directorate Citadel. Kestrel and Harrow are weapon families, not places.
