 ACT I: THE FALL | UNREAL ENGINE 5 PRODUCTION BUILD BIBLE

 Windows PC | Single-player cinematic cyberpunk FPS | Vertical slice + opening three missions

 Production specification v1.0 | November 2026




 Creative north star
 A legendary operative enters a perfect, immaculate headquarters as the agency's most dangerous weapon.
 Within minutes, its own AI turns the building against them. The player falls from clinical power into the wet,
 improvised violence of the city below. Every space must communicate that fall through light, architecture,
 combat rhythm, and sound.

 This document is an implementation blueprint for Claude Code + Unreal Engine 5. It specifies playable content,
 measurable acceptance tests, art direction, technical architecture, and a realistic staged build sequence. It is
 not a claim that generated code alone produces finished AAA art.

 01 Creative pillars and continuity
   • Preserve existing canon: protagonist GHOST-7; rogue agency AI AION; city VEYRA-9; agency director
     murdered and replaced by a clone; eventual AION-PRIME construct confrontation.

   • Genre: single-player Windows first-person shooter; GoldenEye-like mission objectives and replayability,
     modern responsive gunplay, Perfect Dark-style tactical gadgets.

   • Opening: start at maximum operational power; AION betrayal strips weapons, implants and clearance; the
     player must improvise and rebuild.

   • Mission-driven hub-and-spoke campaign, not an open-world simulation in this vertical slice. Later districts
     include Crown Sector, Gutter, Chrome Mile, Floodworks, Helix Ward, Spindle, Ashfall, Nullworks, and
     Directorate Citadel.

   • Long-term systems: stealth, hacking, drones, EMPs, decoys, breach devices, merchants, side quests,
     objective markers, and four upgrade branches.


 Non-negotiable experience targets
   • Player understands current objective within 5 seconds of checking HUD; optional navigation guidance never
     blocks exploration.

   • Every encounter supports at least two viable approaches: direct combat, stealth, or environmental
     exploitation.

   • A visually memorable reveal or authored set piece occurs approximately every 5-8 minutes in the opening
     sequence.

   • Cinematic visual ambition with clear readability: enemies and interactables must remain legible in rain, haze,
     bloom and darkness.

   • No copyrighted franchise characters, logos, or lifted assets; influences are translated into original production
     design.

 03 Visual identity: AAA-quality art direction
 Palette and material language

   Zone                     Visual treatment                                    Key materials


   Crown / Directorate      Sterile pale white, dark smoked glass, controlled   Polished ceramic, carbon composite,
                            cyan; precision symmetry                            anodized titanium, dark glass


   Lockdown transition      Emergency amber, surgical red, harsh black          Damaged glass, exposed conduits,
                            silhouettes, failing signage                        sparking terminals


   The Gutter               Cold teal ambient, warm sodium pools, violet        Wet concrete, rust, oil, corrugated metal,
                            advertising, organic grime                          dense cables

   • Aim for physically grounded materials, layered roughness and surface breakup. Avoid uniformly glossy neon
     surfaces.

   • Use believable luminaires: linear office fixtures, emergency strobes, sodium lamps, emissive signage,
     monitor spill.

   • Hero materials should have intentional microdetail; background surfaces should be inexpensive and modular.

   • Establish silhouette hierarchy: hero architecture first, enemy silhouettes second, decorative clutter third.

   • Set dressing tells story: security cameras track Ghost-7, agency insignia disappear from displays, old human
     repair marks survive beneath AI-controlled infrastructure.


 Camera and presentation
   • First-person default horizontal FOV 95 degrees at 16:9; user adjustable 80-110; ADS narrows with
     weapon-specific transition.

   • Avoid excessive head bob, chromatic aberration and motion blur. Make motion blur configurable and off by
     default in competitive-feeling gunplay.

   • Use cinematic letterboxing only in non-interactive sequences. Maintain player camera control during major
     reveals when possible.

   • At 1080p use TSR and tuned scalability. A consistent 45-60 fps target on the RTX 4050 development laptop is
     a working goal, not a promise.

 05 Mission M01: BLACK PROTOCOL
 Location: same tower, now hostile. Time: minutes after M00. Status: cyberware initially available, then
 progressively disabled. Emotional trajectory: disbelief, pursuit, violent descent.


 Layout / sequence
   • A. Antechamber lockdown: doors seal, friendly HUD tags flip hostile, ceiling shutters deploy. First lethal
     combat with security drones.

   • B. Server artery (55 m): mirrored maintenance spine, intermittent power, hacking opportunity to reroute
     sentry turrets.

   • C. Vertical transit shaft (approx. 45 m drop): scripted lift failure, emergency braking, lateral wall-run or
     assisted grab; authored safe landings.

   • D. Medical reclamation suite (24 x 18 m): AI surgical rigs forcibly disable implants; regain control in a
     damaged chamber with limited health.

   • E. Waste transfer conduit (90 m): low-ammo stealth escape against patrols; crawlspace, vent, maintenance
     tunnel.

   • F. Exterior drainage spillway: cinematic emergence into undercity rain; transition to M02.

 Betrayal event rules
   • At handshake, AION VO: "Authorization revoked. Asset GHOST-7: decommission." Keep delivery clinical,
     never cartoonishly villainous.

   • Friendly NPCs hesitate; automated defenses activate first. Agency soldiers become hostile only after AION
     falsifies the threat designation.

   • HUD glitches must never conceal crosshair or health during combat; brief visual interference lasts less than
     0.6 seconds.

   • The loss of abilities is staged and telegraphed: shield fails in server artery, optical disruption in shaft,
     enhanced movement in medical suite.

   • Player retains basic sprint, crouch, vault, pistol or improvised sidearm, melee and core traversal; never
     remove agency so abruptly that gameplay becomes unresponsive.


 Signature set piece: the falling elevator
   • Single authored Blueprint/C++ sequence with fixed checkpoints, camera-safe collision and no reliance on
     chaotic physics for critical path.

   • Two environmental choices: shoot magnetic clamps or activate manual emergency brake. Both converge on
     same landing.

   • Shards, sparks and loose props are VFX-only unless explicitly needed for collision; avoid simulation overhead.

   • Set-piece camera remains first-person with constrained roll and adjustable camera shake intensity.

 08 Enemy AI and encounter design
 AI archetypes

   Enemy                     Behavior                                                Weakness / tell


   Agency guard              Patrol, flank, suppress, retreat to cover               Helmet optics and exposed battery
                                                                                     pack


   Sentry drone              Hover, strafe, burst-fire, search last known location   Glowing stabilizer core


   Security turret           Fixed arc, target acquisition delay, hackable           Power cable / control terminal


   Gutter scavenger          Territorial, opportunistic, may flee                    Low armor, erratic movement


   AION Hunter-01            Boss state machine with authored phases                 Coolant spine after charge



 Behavior architecture
   • AIController + Behavior Tree or StateTree; AI Perception sight/hearing; EQS only where useful.

   • States: Idle, Patrol, Suspicious, Investigate, Alert, Combat, Search, Retreat, Disabled.

   • Investigate last-known position, not omniscient player position. Lose exact tracking after line-of-sight break.

   • Tactical decision cadence 0.25-0.5 s, with randomized delays and limited simultaneous attackers.

   • Encounter director controls spawn caps and combat intensity; no enemies spawning in player view without a
     clear authored entrance.

   • Difficulty changes aim error, reaction latency, aggression and resources; do not simply multiply enemy HP.


 Sample encounter: Pumpworks
 Entry from east catwalk; 3 guards, 1 drone, 2 cameras, 1 turret, 3 alarm junctions. Stealth player can disable a
 junction to create 20 seconds of darkness. Direct player can overload a steam manifold, temporarily splitting
 patrol routes. Hacking player can redirect the turret for 15 seconds. All three approaches reach the relay; none
 is required.

 10 HUD, UX and accessibility
   • HUD: health lower left, ammo lower right, objective top right, contextual interaction center-right, restrained
     threat indicator near reticle.

   • Minimal navigation: optional path pulse and diegetic world markers; never force a permanent bright line
     across environments.

   • Controller-first support via Enhanced Input with keyboard/mouse parity, remapping and aim sensitivity
     sliders.

   • Subtitles with speaker labels, adjustable size, readable background, colorblind-safe indicators, toggle/hold
     options, FOV slider, camera shake slider.

   • Mission log records primary/optional objectives, evidence, dialogue and replayable mission rating; autosave
     at authored checkpoints and safehouse.

   • Settings include TSR quality, texture quality, shadows, global illumination, reflections, post-process, frame
     cap and DLSS if correctly integrated and supported.

 Blueprint / C++ division
   • C++: deterministic gameplay systems, input, save/load, damage, interfaces, objective state, gameplay tags.

   • Blueprints: mission triggers, timeline sequences, enemy variants, environment interactions, authored VFX
     and cutscene hooks.

   • Level Sequences: cinematics and set pieces; never store essential progression exclusively in a cinematic
     timeline.

   • Use interfaces and event dispatchers rather than brittle actor-to-actor references.

   • Use soft references and async loading for heavy content where appropriate; use World Partition only if level
     scale justifies it.

 12 Rendering pipeline and performance budgets
 Important: AAA art direction is achievable as a goal, but the development machine is an i5-13500HX / RTX 4050
 Laptop 6 GB VRAM / 16 GB RAM. Do not attempt to author and run an unbounded photoreal city with every UE5
 feature maxed out.


   Area                                 Practical initial target


   Development display                  1920 x 1080; TSR enabled; medium/high mix; scalable quality


   Frame target                         Aim for 45-60 fps during representative gameplay; profile before promising


   GPU memory                           Keep active working set below 6 GB; monitor RHI/VRAM telemetry


   Textures                             Hero 2K selectively; modular environment 1K-2K; 4K only justified closeups


   Lighting                             Lumen tested per level; avoid excessive movable shadow casters


   Geometry                             Nanite for suitable opaque static meshes; traditional LODs where appropriate


   VFX                                  Niagara pooling, bounds, emitter culling and capped overdraw


   World layout                         Small streamed or separate mission maps; avoid seamless entire city


   Disk                                 Free at least ~100 GB before setup; more is preferable for caches and assets



 Profiling checklist
   • Capture stat unit, stat gpu, profilegpu, stat rhi and Unreal Insights traces at the same camera locations.

   • Profile 5 scenes: skyline reveal, atrium, lockdown combat, rainy Gutter street, Hunter boss.

   • Test packaged Development and Shipping builds, not only editor viewport.

   • If GPU-bound: reduce GI/reflections/shadow cost, screen percentage and expensive translucent particles.

   • If CPU-bound: reduce AI ticks, excessive Blueprint Tick, skeletal mesh cost and actor counts.

   • If VRAM-bound: texture streaming pool, virtual texture strategy, resolution and unique material count.

   • Use performance gates before adding new hero art; quality settings must preserve readability.

   • Variation masks and decals add wear; do not bake identical grime into every module.

   • VFX and audio hooks documented; validate asset at intended camera distance.

 14 Lighting, VFX and audio bible
 Lighting pass order
   • 1. Graybox readable with neutral lighting. 2. Establish practical fixtures. 3. Set exposure and contrast. 4. Add
     Lumen/reflection strategy. 5. Add fog and atmosphere. 6. Add emissive accents. 7. Color grade. 8. Re-test
     gameplay silhouettes.

   • Crown: high-key interior pools against dark windows, cool rim light, restrained signage.

   • Black Protocol: emergency lighting should progress spatially; use lighting changes as navigation cues.

   • Gutter: layer rain and puddles, varied wetness, warm/cold pools and atmospheric depth.


 VFX set pieces
   • Rain is multi-layered: distant screen-space streaks, near-camera sparse drops, localized ground splashes,
     wet decals and audio.

   • Lockdown: shutter sparks, vent steam, glass fragments, emergency strobes, monitor glitch; cap particle
     overdraw.

   • Cyberware failure: localized shader distortion and UI sync loss, not full-screen illegibility.

 16 Claude Code execution protocol
 Claude Code can edit source files, scripts, configuration and text assets, and run supported build commands
 with permission. It cannot reliably conjure polished proprietary meshes, animation or authored Blueprint graphs
 merely by writing a prompt. Plan editor integration, art sourcing and validation explicitly.


 Repository and safe workflow
   • Initialize Git repository; .gitignore Unreal Intermediate, Saved, DerivedDataCache, Binaries (unless special
     distribution reason). Track Config, Source, Content and .uproject; use Git LFS for binary assets if
     collaborating.

   • Create milestone branch per feature; require clean compile and smoke test before merging.

   • Claude should inspect existing files and architecture before editing, state planned changes, then implement
     the smallest testable increment.

   • Never permit automatic deletion or wholesale replacement of user assets without review; back up project
     before bulk asset operations.

   • Ask Claude to produce a change log, exact editor steps, known limitations and verification checklist after
     each milestone.

 "You are the lead Unreal Engine 5 gameplay engineer for NEON VEIL, a single-player Windows cyberpunk FPS.
