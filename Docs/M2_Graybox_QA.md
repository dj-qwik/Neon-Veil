## Bugs found and fixed in M2

- Trace aim used a camera rotation that was one frame stale, so follow-up shots in the same frame missed. Fixed: aim now comes from the controller's control rotation.
- Moving target 1 was occluded by the divider, and the drill targets were too far away. Fixed: drill layout adjusted.
- Live targets stayed active after the drill ended. Fixed: `Finish()` now deactivates any uncleared targets.
- Pawn failed to spawn inside the solid tram mesh. Fixed: the tram is now hollow.
- Two directional lights both claimed forward shading. Fixed: MoonKey priority set to 1.
- The sky looked like daytime. Fixed: the sun is now below the horizon.
- Floor acted as a mirror. Fixed: roughness raised to 0.5.
- QA tool `FindActor` returned the first partial match (`D_HoloTable_Base` instead of `D_HoloTable`). Fixed: exact matches now win.

## Known gaps (not claimed as working)

Square (reload), Triangle (interact) and the D-pad were not exercised. An Xbox/XInput pad is untested (no hardware).

- **Guards, drone, abilities, surveillance cone, cover prompts:** M3.
- **Bible beats** (the 180 ms glitch, reflection beat), audio, VO: M7. VO is subtitles only, by request.
