NEON VEIL - playtest build 0.1.0 (Prologue, The Glass Crown, Black Protocol escape)

HOW TO PLAY
1. Unzip the whole folder somewhere (don't run it from inside the zip).
2. Double-click NeonVeil.exe.
3. Windows may say "Windows protected your PC" because the game isn't signed.
   Click "More info", then "Run anyway".
4. If it asks to install Microsoft Visual C++ / DirectX prerequisites, allow it
   (or run Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe once).

PC NEEDED
- Windows 10/11, 64-bit, DirectX 12
- Graphics card with 8 GB of video memory (RTX 3060 / RX 6600 or better)
- 16 GB RAM, about 10 GB free disk space

CONTROLS (keyboard + mouse; a gamepad works too)
- WASD move, mouse look, Space jump, Left Shift sprint, Ctrl or C crouch
- Left mouse shoot, right mouse aim, R reload, V melee, mouse wheel switch weapon
- E or F use / interact, H holster, N navigation guide
- Q / G / T abilities (optical disruption, kinetic shield, drone uplink)
- P pause menu (Options: sensitivity, volume, graphics, subtitles)
- Tip: you can shoot out lights.

The game saves at checkpoints automatically. It is an early build: expect rough edges.
Please send your notes, bugs and screenshots to whoever shared this with you.
